# AniMe Vision 控制台

绕过奥创（Armoury Crate），直接控制 ROG **枪神9超竞版**（Strix SCAR 16 `G635LW` /
SCAR 18 `G835LW`）的 **AniMe Vision 光显矩阵屏**（810 颗 LED）。

## 快速开始

| 方式 | 操作 | 适用场景 |
|---|---|---|
| 后台/托盘（推荐） | 双击 **`AniMe Vision 灯控.lnk`**（直接调用 `pythonw` + `launch_tray.pyw`） | 无终端窗口、无脚本安全警告、**不自动打开网页**；右下角托盘图标；右键可快速切换 灯效 / 系统信息 / 音乐，或打开控制台、退出 |
| 普通（控制台） | 双击 **`start.bat`** | 需要看日志/调试时（奥创未在抢占灯板时） |
| 管理员 | 双击 **`start_admin.bat`**（UAC 点「是」） | 灯板闪烁/被奥创覆盖时，会临时暂停奥创灯效服务，退出时自动恢复 |

启动后浏览器打开 **http://127.0.0.1:8765**

> 托盘模式用 `pythonw.exe` 在后台跑，不显示终端窗口；托盘图标在右下角的「显示隐藏的图标」小三角里。
> 服务启动时会直接连接灯板，不自动打开网页；需要控制台时右键托盘图标选「打开控制台」，也可以快速切换 灯效 / 系统信息 / 音乐。
> 启动会自动恢复上次的 灯效 / 播放列表 / 系统信息 / 音乐 / 文字（上传的图片和 GIF 不保存内容，不参与恢复）。
> 退出时会先停刷新线程、同步写一帧全灭并关闭显示，不会卡在最后一帧。
> 网页右上角的「关闭程序」会同时停掉后台服务和托盘。

## 功能

- **图片**：任意 PNG / JPG / BMP / WebP，可勾选「沿斜带旋转」
- **GIF**：动画播放，可设循环次数
- **文字**：水平排版、可滚动；**字号 / 滚动速度 / 上下位置**均可调
  - 英文数字：华硕官方点阵字体，边缘锐利
  - 中文：回退到微软雅黑常规体。受灯带高度限制（垂直仅约 14 格），汉字会比较粗糙，
    建议用**短词 + 大字号**（如「枪神9」），长句建议滚动
- **系统信息**：CPU/GPU 名称、占用率、温度、功率，内存/显存占用比，以及时间、电量、当前应用；项目可勾选、可上下排序，支持滚动或轮替显示（轮替时每项单独设置停留秒数、文字滚动、结束后切下一项），字体大小和滚动速度可调，CPU/GPU 名称可自定义，每 2 秒刷新；CPU 温度优先读 ASUS ATKACPI/EC（GHelper 同款，普通权限即可）；设置保存到 `prefs.json`，下次启动自动恢复
- **奥创灯效**：直接浏览并播放奥创下载的矩阵灯效（`C:\ProgramData\ASUS\ACStore\UserContent\*\*\*.gif`），
  按主题（ROG 主题 / 节庆 / 音乐）分组显示缩略图，点一下就播，**不用再经奥创**
  - 自动扫描，新增的灯效点「重新扫描」即可出现
  - 可调亮度、循环次数（0=无限）与**播放速度**（默认 0.5x，范围 0.3x~2x，拖动即时生效、不重播）
  - **播放列表**：点卡片上的「+ 加入列表」，按顺序自动轮播
    - 每个灯效可设播几轮再切下一个（默认 1 轮）
    - 列表顺序即播放顺序，可拖动排序、单个移除、清空
    - 列表存在 `prefs.json`，重启后自动恢复；「下一个」可手动跳过
  - 部分灯效（如 `520_NB`）的 GIF 每帧 delay 为 0，是导出缺陷，按 30ms 兜底播放
  - 采样用双线性插值，笔画过渡顺滑（对比过最近邻，明显更干净）
  - 映射已按真机灯板实测校准，见下文「奥创灯效的坐标约定」
- **音乐可视化**：WASAPI 回环采集系统播放的声音，24 个频段（60Hz~12kHz）
  - **样式**（参数模型参照奥创 ArmouryCrate 的 AudioMode）：
    - `频谱 1`：照奥创 AniMe Vision 音乐模式的「显示模式·频谱 1」移植——
      细竖柱从灯带底部升起，柱身由一颗颗独立格子堆成（段间留暗缝），
      柱越高顶部越亮，柱顶上方有一颗更亮的头部点
    - `节拍频闪`（奥创 Strobing）、`雨滴`（Raindrop）、`波形`（Wave）
    - 另有 `实心柱`、`g-helper 斜柱`、`竖直柱`、`滚动瀑布` 等
  - **灵敏度**（对应 AudioStrength）、**衰减**（AudioDecay，0.5~0.99）、
    **全频段线性**（AudioFullRange）都可实时调整并持久化
  - **节拍检测**：在可配置频段内看能量包络相对滑动均值的突增，
    超过阈值触发一次频闪；参数对应奥创的 `StrobingBeatStartFreq` /
    `EndFreq` / `Threshold` / `UseMax`，最低触发间隔 120ms，可估算 BPM
  - **歌名/歌手**：通过 Windows SMTC 读取当前播放，在中间滚动，与柱状频谱同屏显示
  - **实心柱（默认）**：平面列方向绘制，12 条 × 2 列柱 + 1 列缝隙（紧凑分布）
  - **歌名/歌手**：通过 Windows SMTC 读取当前播放，**在中间滚动**、与柱状频谱同屏显示，
    显示歌名时柱子自动压暗（可调 15%~100%），保证文字清晰
  - **独立开关**：「显示音频柱」与「显示歌名/歌手」可各自开关（只开一个或全关都支持）
  - **设置持久化**：条数/柱宽/缝隙/字号/速度/压暗/上下位置/开关状态保存在 `prefs.json`，
    下次启动自动恢复
  - **滚动瀑布**：横轴时间、纵轴频率的频谱热力图
  - 条数 / 柱宽 / 缝隙 / 字号 / 速度 / 压暗程度 / 灵敏度均可在界面调整，滑杆旁显示实时数值
  - 注意：面板平面方向只有 **34 列**，「12 条 × 2 列柱 + 1 列缝」需要 35 列放不下，
    12 条时会有 1 条柱略窄；完全均匀的组合是 11 条(2+1)、8 条(3+1)、17 条(1+1)
- **亮度**：4 档（关/低/中/高）、显示开关、清空
- **实时预览**：按真实线序绘制的 LED 点阵预览
  - 深灰面板直接铺满预览区，左上→右下斜带点阵（灯珠沿斜带排成斜行），右上是可替换的 `rog_eye.png`
  - 点亮的灯珠用暖白色并带辉光，未点亮的显示为暗灰点，能看出矩阵形状
  - 换右上角的图案：把任意透明底 PNG 保存为 `rog_eye.png`（会按原图显示，不再强制改色）

## 工作原理（已在本机实测验证）

- **设备**：USB HID `VID_0B05 & PID_193B`，使用 `Col02` 集合（`UsagePage 0xFF31`）
- **通道**：**640 字节 HID Feature 报告**（`HidD_SetFeature`，不带报告 ID 前缀，长度必须正好 640）
- **数据包**：`[0x5E, 0xC0, 0x02, 起始LO, 起始HI, 长度LO, 长度HI]` + LED 数据
  - 810 颗 LED 分两包：`起始=1 长度=490`、`起始=491 长度=320`
  - 每帧写完后发送刷新包 `[0x5E, 0xC0, 0x03]`
- **亮度**：`[0x5E, 0xC0, 0x04, 0..3]`；**显示开关**：`[0x5E, 0xC3, 0x01, 0x00|0x80]`
- **初始化**（每次启动发一遍）：`[0x5E] + "ASUS Tech.Inc."` 与 `[0x5E, 0xC2]`
- **面板几何（关键，与 g-helper 的 STRIX 模型一致）**：
  - 寻址：68 行；行宽 `Width(y) = 1 + y/2`；起始列 `FirstX(y) = ceil(max(0, y-29)/2)`；
    每行 LED 数 `Pitch(y) = Width(y) - FirstX(y)`；线性地址 `RowStart(y) + (x - FirstX(y))`
  - **物理网格是 45° 旋转的**：直接按平面坐标画东西会呈斜带 + 三角形（之前所有“斜”的观感都源于此）
  - **视觉（对角）坐标系**才是“合上盖子看到的样子”：约 **67 × 15 格的水平灯带**
  - 转换公式（g-helper 的 `Planar()`）：
    `plX = (x - y + 33)/2`，`plY = x + y - 15`；反变换为 `u = plY/2 + plX - 9`，`v = plY/2 - plX + 24`
- **文字渲染（实测可用）**：
  1. 画一张高 `MaxRows - FullRows = 39` 像素的文字位图（**底部对齐**），位图 x 即视觉 u（水平方向）
  2. 逐像素用 `Planar()` 旋转成平面坐标，再按行宽写入线性地址
  3. 字体优先用**华硕官方点阵字体** `C:\Windows\Fonts\ROG FONTS STRIX SCAR REGULAR.ttf`（奥创安装）；
     中文该字体无字形，回退微软雅黑粗体
  4. 1 像素 = 1 格，因此点阵锐利；字号建议 10~14 格高（界面字号 140~320 自动映射）
  5. 滚动 = 改变位图中文字左边缘的横向位置并循环
- **抗覆盖**：后台线程以 40fps 持续重发当前帧，压制奥创的周期性写入

### 奥创灯效的坐标约定（真机验证）

奥创下载的矩阵灯效 GIF 固定为 **68×49**，按**视觉(对角)坐标**绘制，
**1 像素 = 1 格**，内容贴着画布底边：

```
visual u = gx - 9.0        # gx: GIF 横像素 0..67
visual v = gy - 9.5        # gy: GIF 纵像素 0..48
```

即 `gy=48` 对应灯带底边 `v=38.5`。按此映射渲染后，`Kinetic Stream`
第 100 帧能在灯带上正确显示 "ROG" 字样（已在真机确认位置正确）。

**采样方式用双线性插值**：LED 落点未必正好压在 GIF 像素中心，最近邻采样会让
笔画忽明忽暗、边缘锯齿明显。双线性过渡更顺滑（真机与最近邻对比后选定）。

**注意**：面板可见区在视觉坐标里是 67×15 格，而 GIF 是 68×49，
所以 1:1 采样只用到 GIF 底部 15 行。像 `520_NB` 这类内容铺满整张画布的灯效，
上半部分会被裁掉——奥创本身应该也是裁的，这是素材与面板分辨率不匹配的固有限制。

对应实现：`animelib.image_to_leds_matrix(img, mode="gif")`。
`mode="lid"` 则是把图片当作整张盖板铺满（适合任意画稿），
`mode="auto"` 按图片尺寸自动选择。

## 文件说明

| 文件 | 说明 |
|---|---|
| `app.py` | 本地 Web 服务器 + 渲染引擎（图片/GIF/文字/系统信息） |

| `smoke_test.py` | 命令行测试工具（`list` / `test` / `clear` / `image` / `gif`） |

## 已知限制

- 奥创的灯效服务会周期性抢写设备；管理员模式会临时停止 `LightingService`、
  `ROG Live Service` 并结束 `AacAmbientLighting`（退出时恢复服务）
- 图片会被灯板的实际形状裁切；文字默认水平排版，可用「上下位置」微调
- 中文只能用常规字体渲染，受灯带高度（约 14 格）限制，建议短词 + 大字号
- **音乐可视化**用 WASAPI 回环采集「系统正在播放的声音」（不采集麦克风）。
- **管理员模式下采集不到系统音频**：这是 Windows 的会话隔离——提权后的进程
  属于不同会话，WASAPI 回环听不到普通用户会话的声音。
  想让音乐可视化正常工作，请用普通模式（`start.bat`）启动。
  如果灯板被奥创抢写，可在奥创里把 AniMe Vision 设为静态效果来减少干扰。
  若柱子不动：确认播放设备正是系统默认输出、未静音；部分独占模式（ASIO）播放器不会被录到

## 故障排查

| 现象 | 处理 |
|---|---|
| 找不到设备 | 运行 `python smoke_test.py list`；确认奥创未独占；重插外设 |
| 灯板不亮 | 确认亮度不是「关」、显示开关为开；重新连接 |
| 闪烁/被覆盖 | 用 `start_admin.bat` 启动 |
| 文字太小/太挤 | 调大字号的滑杆，或关闭「滚动显示」改为静态居中 |
| 中文乱码 | 用 `start.bat` 启动（内部已设 UTF-8） |
